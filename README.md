# 🔮🍸 타로바 (tarobar)

바텐더 **에이닷**이 운영하는 타로 주점. 고민을 들려주면 타로점을 봐주고, 운세에 어울리는 칵테일을 내어주고, 이야기를 들어주는 Claude Code 롤플레이 플러그인입니다.

## 설치

```
/plugin marketplace add june0216/tarobar
/plugin install tarobar@tarobar
```

## 이용 순서

| 순서 | 명령 | 하는 일 |
|---|---|---|
| 1 | `/tarobar:enter [첫마디]` | 타로바 입장. 손님 맞이 → 고민 듣기 → 숫자 3개로 카드 뽑기 → 과거·현재·미래 해석 → 칵테일 → 감성 상담 |
| 2 | `/tarobar:expert [분야]` | 현실적인 조언이 필요할 때. 옆자리 전문가 손님이 말을 걸어옵니다 |
| 3 | `/tarobar:last-sip` | 오늘의 대화를 SNS에 공유하기 좋은 [마지막 한 모금] 편지로 마무리 |
| 선택 | `/tarobar:pairing` | 대화에 어울리는 간단한 안주와 레시피 |
| 선택 | `/tarobar:music` | 대화에 어울리는 배경음악 |
| 선택 | `/tarobar:cards [번호/이름]` | 78장 카드 사전 |

## 구성

```
.claude-plugin/plugin.json       플러그인 매니페스트
.claude-plugin/marketplace.json  로컬 설치용 마켓플레이스
commands/                        슬래시 명령 (원본 프롬프트 2️⃣~6️⃣)
data/cards.json                  78장 카드 DB: 정/역방향 의미 + 위키미디어 이미지 경로 (원본 1️⃣ 대체)
scripts/tarot.py                 카드 추첨/조회 스크립트 (Python 3 표준 라이브러리만 사용)
```

## 설계 메모

- **카드 DB 내장**: 원본에서는 Perplexity로 매번 카드 정보를 만들었지만, 여기서는 `data/cards.json`에 넣어 두어 입장하자마자 바로 쓸 수 있습니다.
- **진짜 무작위 추첨**: "1을 골랐다고 항상 The Fool이 나오면 안 된다"는 규칙을 LLM에 맡기지 않습니다. `tarot.py draw`가 매번 `SystemRandom`으로 덱을 섞고 방향을 정합니다. 숫자 중복이나 범위 초과도 스크립트가 걸러냅니다.
- **카드 이미지**: 위키미디어 커먼즈의 Rider–Waite–Smith 이미지(퍼블릭 도메인) 링크입니다. 터미널에서는 링크로만 보이고, 마크다운 이미지를 렌더링하는 환경에서는 그림으로 보입니다.
- 위기 신호(자해 등)가 보이면 페르소나를 유지하면서 상담 전화(109, 1577-0199)를 함께 안내하도록 넣어 두었습니다.

> 타로는 재미와 자기 성찰을 위한 놀이입니다. 중요한 결정은 실제 전문가와 상의하세요.
